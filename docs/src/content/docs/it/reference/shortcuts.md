---
title: Scorciatoie da tastiera
description: Le scorciatoie di Granello, nell'app, in una nota e nella Libreria.
---

## Ovunque

| Scorciatoia | Cosa fa |
| --- | --- |
| ⌘N | Nuove note |
| ⌘K | Cerca nei meeting |
| ⌘, | Impostazioni |

## In una nota

| Scorciatoia | Cosa fa |
| --- | --- |
| `/` | Menu dei comandi |
| ⌘F | Trova e sostituisci |
| ⌘⇧H | Evidenzia il testo selezionato |
| `@` | Menziona una persona |
| `!` + spazio | Riquadro |
| `#` + spazio | Titolo (`##`, `###` per quelli più piccoli) |
| `-` + spazio | Elenco puntato |
| `1.` + spazio | Elenco numerato |
| ⇧⌘M | Segna questo momento, mentre registri |

## In trova e sostituisci

| Scorciatoia | Cosa fa |
| --- | --- |
| Invio | Corrispondenza successiva |
| Maiusc Invio | Corrispondenza precedente |
| Esc | Chiudi |

## Nella Libreria

| Scorciatoia | Cosa fa |
| --- | --- |
| ↑ ↓ | Muove nella colonna |
| ← → | Cambia colonna |
| Invio | Apre il meeting |
| ⌘ clic, Maiusc clic | Seleziona più meeting |
| ⌘A | Seleziona tutti i meeting elencati |
| Esc | Annulla la selezione |
