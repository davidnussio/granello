---
title: Keyboard shortcuts
description: The shortcuts of Granello, in the app, in a note and in the Library.
---

## Everywhere

| Shortcut | What it does |
| --- | --- |
| ⌘N | New notes |
| ⌘K | Search your meetings |
| ⌘, | Settings |

## In a note

| Shortcut | What it does |
| --- | --- |
| `/` | [Command menu](/reference/slash-commands/) |
| ⌘F | Find and replace |
| ⌘⇧H | Highlight the selected text |
| `@` | Mention a person |
| `!` + space | Callout |
| `#` + space | Heading (`##`, `###` for smaller ones) |
| `-` + space | Bullet list |
| `1.` + space | Numbered list |
| ⇧⌘M | Mark this moment, while recording |

## In find and replace

| Shortcut | What it does |
| --- | --- |
| Enter | Next match |
| Shift Enter | Previous match |
| Esc | Close |

## In the Library

| Shortcut | What it does |
| --- | --- |
| ↑ ↓ | Move in the column |
| ← → | Change column |
| Enter | Open the meeting |
| ⌘-click, Shift-click | Select several meetings |
| ⌘A | Select all the listed meetings |
| Esc | Clear the selection |
